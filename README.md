# Sharjah Driving Theory Practice

A free, offline-friendly practice test for the Sharjah driving theory exam.
Open `index.html` in any browser, or use the GitHub Pages link.

- Multiple-choice questions with instant marking and explanations
- Topic filter, flag for review, per-topic results and full review
- Results are saved only in your own browser

Questions are based on the Sharjah Driving Institute handbook *Basics of Driving*
(4th edition, 2021). Always check against the official handbook and the Sharjah Police website.
